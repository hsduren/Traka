# 002 — 在 macOS 2 VM 验收

状态：已接受。用户明确要求测试不得占用主机。

主机仅编辑与编译。通过现有 SSH 主机 `macos2` 部署到来宾 `~/Applications/Traka-P0-QA/Traka.app`，运行 `--self-test` 及应用自身的 `--ui-smoke`。后者直接调用应用控件回调，验证真实窗口、播放时间推进、状态和异步渲染，并生成自身组件截图。无需主机鼠标、前台窗口或屏幕捕获权限。此测试覆盖应用控件和模型衔接，不代表系统文件选择器、实体麦克风或实际鼠标拖动的完整验收。

VM 没有启用音频输入通道，真实录音与硬件延迟保留为人工验收项。不会自动扩大主机或来宾的麦克风/辅助功能权限。
