# 001 — 原生 P0 音频工作站

状态：已接受。来源：用户指定的前置会话，当前会话确认最终名称 Traka 并要求只做 P0。

复用 Tracktion Engine 的音频模型、传输控制、录音、撤销与渲染，使用 JUCE 编写独立的轻量时间线。采用 CMake，避免 Swift 桥接与第二套项目模板。只实现音频制作最小闭环。示例音频由本项目生成，不复制 upstream 媒体。

项目文件及媒体目录必须一起移动，导出固定 48 kHz / 24-bit / stereo。避免音频覆盖原件，导出成功后才替换目标文件。新项目草稿和自动保存优先保障本地工作恢复。

前置会话中的 Trako 名称被用户纠正为 Traka；未对外分发任何旧名项目，无数据迁移需求。完整 DAW、品牌图标、App Store 和公证不属于 P0。
