# Traka P0 产品约定

- 最终产品名 Traka，Bundle ID `com.yxf.traka`，当前版本 0.1.0。
- 原生桌面应用，C++20 / JUCE / Tracktion Engine，最低 macOS 13。
- 核心闭环：音频导入、多轨播放、单轨录音、基础剪辑/混音、项目保存重开、WAV 导出。
- 项目为 `.traka` XML 与同名 `.traka.media` 文件夹，音频使用相对路径；原始导入文件不被修改。
- 自动保存到本机，用户保存后继续自动更新该项目。麦克风仅由录音/音频设置启用，输入监听关闭。
- 无账户、云端、遥测、运行时网络依赖或上架动作。应用许可页展示公开源码地址。只交付开发 MVP，不扩展完整 DAW。
- 接受完整开源：应用代码 AGPL-3.0-or-later，依赖保留各自许可证。

- UI 交互与运行验收仅在 macOS 2 VM 内进行，不占用主机窗口与鼠标；主机只进行源码编辑和编译。

- 用户已授权创建公开 GitHub 仓库 `hsduren/Traka`，首版 `v0.1.0`。每次发布同步提交对应源码、保留版本标签和完整依赖源码包。
